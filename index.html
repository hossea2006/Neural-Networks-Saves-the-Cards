Deep NN Architecture

def build_deep_model(input_dim):
    model = keras.Sequential([
        layers.Input(shape=(input_dim,)),

        # Block 1: broad pattern detection
        layers.Dense(128, activation='relu', kernel_regularizer=regularizers.l2(1e-4)),
        layers.BatchNormalization(),
        layers.Dropout(0.3),

        # Block 2
        layers.Dense(64, activation='relu', kernel_regularizer=regularizers.l2(1e-4)),
        layers.BatchNormalization(),
        layers.Dropout(0.3),

        # Block 3
        layers.Dense(32, activation='relu', kernel_regularizer=regularizers.l2(1e-4)),
        layers.BatchNormalization(),
        layers.Dropout(0.2),

        layers.Dense(16, activation='relu'),
        layers.Dense(1,  activation='sigmoid')  # fraud probability
    ], name='deep_model')
    return model

04 Findings

Key takeaways

What the experiments revealed about fraud detection with neural networks.

⊕SMOTE works

Synthetic oversampling of the minority class gave the model enough fraud examples to learn meaningful patterns instead of trivially predicting "legitimate" for everything.

↑Depth helps

The deeper network with BatchNorm and Dropout outperformed the baseline across all metrics. Regularization prevented overfitting on the tiny fraud class.

⇌Autoencoders are competitive

The anomaly-detection approach matched supervised models on ROC-AUC without ever seeing a fraud label during training, practical when labeled fraud data is scarce.

◎Threshold matters

Moving the decision threshold below 0.5 meaningfully improved recall (caught frauds) with manageable false alarms. In production, tune against the actual business cost of each error type.
